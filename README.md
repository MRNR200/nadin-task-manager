# Nadin Task Manager API

این پروژه یک سامانه مدیریت تسک است که با فریم‌ورک FastAPI پیاده‌سازی شده است.

## 🚀 ویژگی‌ها
- احراز هویت با JWT (ثبت‌نام و ورود)
- مدیریت تسک‌ها (ایجاد، ویرایش، حذف، دریافت)
- رعایت دسترسی‌ها (هر کاربر فقط تسک‌های خودش را می‌بیند)
- امکان آپلود عکس پروفایل و پیوست فایل برای تسک‌ها
- هندلینگ سراسری خطاهای ۵۰۰

## ⚙️ راهنمای راه‌اندازی

۱. ساخت محیط مجازی و نصب پکیج‌ها:
`pip install -r requirements.txt`

۲. ساخت دیتابیس MySQL به نام `nadin_task_db` و تنظیم یوزرنیم و پسورد در فایل `database.py`.

۳. اجرای پروژه:
`uvicorn main:app --reload`

مستندات API (Swagger) در آدرس `http://127.0.0.1:8000/docs` در دسترس است.
